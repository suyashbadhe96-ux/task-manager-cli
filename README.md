\# Task Manager CLI



A simple Command Line Task Manager built using Node.js.



\## Features



\- Add tasks

\- Delete tasks

\- List all tasks

\- Stores tasks in JSON file

\- Prevent duplicate tasks



\## Technologies Used



\- JavaScript

\- Node.js

\- File System (fs)

\- Async/Await



\## How to Run



\### Add Task



```bash

node app.js add "Learn JavaScript"

````



\### List Tasks



```bash

node app.js list

```



\### Delete Task



```bash

node app.js delete "Learn JavaScript"

```
